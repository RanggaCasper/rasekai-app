# 🎬📚 RaSekai

RaSekai is a **multi-content entertainment application** that brings together **anime, donghua, comics, and novels** in one modern and unified platform.

It is designed to provide a **smooth, immersive, and convenient experience** for enjoying different types of storytelling content—whether you prefer watching, reading, or both.

---

## ✨ Features

### 🎥 Anime & Donghua
- Browse and watch anime and donghua content
- Clean viewing interface optimized for mobile
- Smooth playback experience

### 📚 Comics & Novels
- Comfortable reading experience for comics and novels
- Optimized layouts for long reading sessions
- Simple and distraction-free reader

### 🔄 Continue Where You Left Off
- Automatically saves your progress
- Resume watching or reading instantly

### 🎨 Modern Interface
- Clean and intuitive UI inspired by popular streaming platforms
- Easy navigation across different content types
- Designed for both light and dark environments

### 🚀 Performance Focused
- Fast loading and smooth navigation
- Lightweight and efficient Android build
- Optimized for a wide range of Android devices

## 📱 Installation (Android)

1. Download the APK from the **Releases** page
2. Enable **Install unknown apps** on your Android device:
   - Settings → Security or Privacy
3. Open the APK file
4. Follow the on-screen installation instructions
